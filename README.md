# Skin-cancer-detection-using-multimodal-and-explainable-AI
## Trained Model Weights

The trained Vision Transformer (ViT) checkpoint is available here:

[Download `vit_final_v1.pt` from Google Drive] 
https://drive.google.com/drive/folders/1dJq_1YYNJwVSa-7d5JnY8smKtKd0iC52?usp=drive_link
**Setup instructions:**
1. Download the checkpoint from the link above.
2. Create an `outputs` folder in the project root if it doesn't exist.
3. Place `vit_final_v1.pt` inside the `outputs` folder.
4. Install the dependencies listed in `requirements.txt`.
5. Run the inference notebook or script.

The model is already trained, so you do not need to retrain it.
