# Concepts

## Explanation target

The model component/function whose output an explanation describes. In this project, clinical-branch TreeSHAP, ViT-branch image maps, and CWF-level modality Shapley must be named separately.

## Exact Shapley reference

The exact Shapley allocation for a declared cooperative game, including its players, coalition payoff, background, and missing-player intervention. Exactness is relative to that specification, not a claim of causal or clinical ground truth.

## Planted cue

A controlled image or tabular signal with known construction and label relationship, introduced for an evaluation protocol. No planted-cue experiment is recorded as run in the current read-only state.
